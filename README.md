# AMRBot——机器人主题原版模组

AMRBot是一个以机器人为主题的原版模组，加入了3种模块化的机器人和10个不同功能的模块。玩家可以组装属于自己的机器人，辅助玩家探索和战斗。  
原版模组加入了一个全新的群系，其中会生成飞船结构，玩家可以在内部找到材料，模块甚至机器人。

## 机器人

原版模组添加了三种机器人：通用机器人，飞行机器人，重型机器人。  
通用机器人和飞行机器人放置后可分别在地面和空中跟随玩家移动，重型机器人则无法主动移动，但可乘上船或矿车运动。

### 模块与组装
飞行机器人有2个模块槽位，通用机器人有3个，重型机器人有4个；每种机器人可安装的模块有限制，详情可见模块功能版块。  
玩家可在组装台给机器人组装模块。详情可见组装台版块。

### 机器人生命值
机器人通常不会被攻击，但机器人仍拥有生命值：生命值归零后，机器人会损坏并以物品形式掉落。  
通用机器人有40生命值，飞行机器人为20，重型机器人为100。

### 部署与控制
主手持有机器人并长按2秒可部署机器人。  
通用机器人和飞行机器人单个玩家总计最多可部署3个，重型机器人则无限制。  
在非潜行状态下对机器人右键可唤出机器人操作终端。在终端中，玩家可查看机器人安装的模块信息等，并调节每个模块的启用状态。此外，还可以修改机器人的跟随状态，解除机器人部署等。

### 模块功能和耗电
机器人执行模块功能会消耗电量。若电量不足则无法执行对应的功能。对通用和飞行机器人，执行模块功能直接消耗绑定的玩家的电量；对于重型机器人，消耗的为自身电量，玩家可使用自己的电量为重型机器人充电。

玩家回收重型机器人时可以回收（重型机器人剩余电量-10）的电量。

## 电量系统
原版模组为玩家新增了一个新的资源类型：电量。执行机器人模块功能，使用电棍等行为均会消耗电量。  
电量初始上限为100，回复速度为1/6秒。穿戴指定的供能装备可增加电量上限或回复速度。  

## 模块与模块功能
原版模组新增了10个功能不同的模块，按照功能可分为战斗型模块和探索型模块。

- 战斗型模块：主动防御系统，音波生成器，负面效果产生器，M242链式炮，导弹发射器；
- 探索型模块：摔落保护模块，修理服务模块，外置背包，太阳能电池板，矿物探测仪。

各个模块的功能如下：

### 主动防御系统
生效后，每0.25秒尝试拦截一次弹射物，对于通用和飞行机器人，不会拦截其主人发射的弹射物。

- 类型：战斗型模块
- 耗电：4/次

### 音波生成器
生效后，自动锁定周围30格内的敌对生物，发射伤害为12/发的音波攻击目标。

- 类型：战斗型模块
- 耗电：4/次

### 负面效果产生器
生效后，每15秒对40格内的敌对生物造成10秒的缓慢2和虚弱2效果。

- 类型：战斗型模块
- 耗电：0
- 只能安装在重型机器人上

### M242链式炮
生效后，对32格内的敌对单位连续发射伤害10/发的炮弹，但攻击时会有随机的偏移

- 类型：战斗型模块
- 耗电：2/发

### 导弹发射器
安装后，玩家使用导弹发射指示器可激活瞄准界面，瞄准目标后机器人会向指定目标发射一枚伤害为20的导弹。

- 类型：战斗型模块
- 耗电：10/发

### 外置背包
安装后，玩家可在潜行状态下拿着物品与机器人互动将物品放入外置背包，空手与机器人互动取出最后放入的一个物品堆叠。背包上限为16项物品。

- 类型：探索型模块
- 耗电：0

### 摔落保护模块
安装后，在50格内的玩家可能受到摔落伤害时，触发摔落保护效果以免受此次伤害。冷却20秒。

- 类型：探索型模块
- 耗电：5/次

### 修理服务模块
安装后每秒有10%概率随机触发，8格内玩家装备或主副手物品耐久有损耗时，消耗电量修复随机三件物品1点耐久。

- 类型：探索型模块
- 耗电：1/次

### 太阳能电池板
安装后若光照条件充足，则缓慢回复自身（重型）或绑定玩家（通用或飞行）的电量。

- 类型：探索型模块
- 耗电：0

### 矿物探测仪
安装后，每2秒指示一次周围的矿物点位置。

- 类型：探索型模块
- 耗电：1/次

## 空白模块和模块手册
所有模块均需空白模块和其他两件材料在锻造台中合成。  
具体的配方可见模块手册的提示。  
固定样式的模块手册会在部分飞船结构中刷新，也可在飞船战利品箱中概率获得。  
在ui中显示为缩略形式，拿在手上或放置在物品展示框或展示架上可观察具体配方内容，也可作为装饰。

## 组装台和组装机制

机器人需要在组装台上组装模块。

### 组装台
组装台为原版模组新增的方块。拥有0硬度，可以被任意工具或空手破坏。拥有1格完整的碰撞箱。

### 模块组装
玩家手持机器人与空闲组装台互动即可将机器人放置在组装台上，此后手持模块从**组装台上表面**对准机器人模型的模块插槽互动即可将模块安装在机器人上；空手对安装了模块的插槽互动可将模块拆卸下来。

安装完成后，按左shift+右键可将机器人从组装台取下。

模块安装时遵循如下限制：
- 战斗型模块仅能安装在战斗模块插槽上，探索类模块则无限制；
- 单个机器人只能安装一个战斗型模块；
- 对于飞行机器人和重型机器人，若中部的一个插槽安装了战斗型模块，则另一个插槽无法安装模块。
- 同一个机器人上不能安装两个相同的模块；
- 负面效果产生器、导弹发射器只能安装在重型机器人上。

注：通用机器人的中间插槽，飞行机器人的后方插槽，重型机器人的中间两个插槽为战斗模块插槽。其余插槽为探索模块插槽。


## 装备与武器
加入了一套盔甲，可以提供电量增益。加入了一件武器。

### 供能头盔
- 属性：+2护甲值，+1盔甲韧性，+20最大电量
- 耐久：256

### 供能胸甲
- 属性：+6护甲值，+2盔甲韧性，+3电量回复速度
- 耐久：320

### 供能护腿
- 属性：+5护甲值，+1盔甲韧性，+2电量回复速度
- 耐久：300

### 供能战靴
- 属性：+2护甲值，+1盔甲韧性，+1电量回复速度
- 耐久：288

### 充能电棍
- 属性：6攻击伤害，1攻击速度
- 无法附魔
- 特性：电量大于3时，可消耗3电量对攻击目标施加10秒缓慢1和虚弱1效果。

## 群系与结构
新增了一个生物群系：陨落焦土（FallLand）。  
在群系中玩家可找到废弃飞船，其中可找到箱子，可获取相关的机器人、模块等。  
模块配方手册也会在飞船中生成。

### 敌人
在飞船中会固定刷新敌人：飞船守卫，穿戴全套的供能装备和充能电棍，死亡后不会刷新。  
在飞船守卫附近时玩家会获得缓慢和电量恢复速率提升效果。  
击杀飞船守卫会掉落一个空白模块。
